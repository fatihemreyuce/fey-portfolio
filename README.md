# FEY Portfolio

Personal developer portfolio built to showcase my experience, projects,
technical skills, and software development journey.

The project is built with **Next.js, React, TypeScript, and Tailwind CSS**
with support for multiple languages, theme switching, and a server-side
contact system.

## ✨ Features

- Responsive developer portfolio
- About and experience sections
- Featured projects showcase
- Technical skills overview
- Hobbies and personal interests
- FAQ section
- Contact form
- Dark and light theme support
- Multi-language interface
- Server-side email handling
- Responsive navigation and layouts

## 🛠 Tech Stack

### Frontend

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

### Application

- Next Themes
- Firebase Admin
- Resend
