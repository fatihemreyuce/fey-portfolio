# FEY Portfolio

Personal developer portfolio built to showcase my experience, projects, technical skills, and software development journey.

The project is built with **Next.js, React, TypeScript, and Tailwind CSS**, with support for multiple languages, theme switching, and a server-side contact system.

---

## ✨ Features

- Responsive developer portfolio
- About and experience sections
- Featured projects showcase
- Technical skills overview
- Hobbies and personal interests
- FAQ section
- Contact form
- Dark and light theme support
- Multi-language interface
- Server-side email handling
- Responsive navigation and layouts

---

## 🛠 Tech Stack

### Frontend

- **Next.js 16**
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **Lucide React**

### Application & Services

- **Next Themes** — theme management
- **Firebase Admin** — server-side Firebase integration
- **Resend** — email delivery

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/fatihemreyuce/fey-portfolio.git
cd fey-portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file in the project root and configure the environment variables required by the application.

> Never commit private API keys or credentials to the repository.

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
